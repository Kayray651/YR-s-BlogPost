### 关键知识点（Hexo + Vercel）
- Hexo `source_dir: source`，只有 `source/` 下的文件会被复制到 `public/`。根目录的自定义文件夹不会被打包。
- `_config.yml` 的 `include`/`exclude` 只对 `source/` 子目录生效，管不到根目录文件夹。
- `.gitignore` 正确排除了 `db.json`、`public/`、`node_modules/`，Vercel 每次从干净仓库构建。
- `vercel.json` 只有 headers 配置，无 build 配置，靠 Vercel 自动检测（npm run build → hexo generate，输出 public）。
