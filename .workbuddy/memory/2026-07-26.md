# 2026-07-26 工作日志

## 微信公众号同步脚本开发

### 背景
用户要实现"一键"将 Hexo 博客文章同步到微信公众号。经调研确认：
- 用户是**个人订阅号**，2025年7月起微信回收了个人号的 freepublish（发布）接口权限 → 只能 API 创建草稿，发布需手动
- IP 白名单限制 → GitHub Actions 不可行（IP 不固定），只能本地运行
- 图片防盗链 → 文章中的图片必须通过 `uploadimg` 接口上传到微信素材库，替换为微信 CDN URL

### 交付物
1. `scripts/sync-wechat.mjs` — 主脚本（ESM，Node 22）
2. `.env.example` — 凭证模板
3. `.gitignore` — 新增 `.env` 和 `.wechat-sync.json`
4. `package.json` — 新增 `sync-wechat` 脚本 + `marked`/`gray-matter` 依赖

### 脚本功能
- `pnpm sync-wechat` — 同步未同步文章到公众号草稿箱
- `pnpm sync-wechat -- --force` — 强制重新同步所有
- `pnpm sync-wechat -- --dry-run` — 试运行（不调 API，仅检查转换）
- Markdown → 微信兼容 HTML（保留 `<font>` 标签，`<center>` 转 `<section>`，加 inline style）
- 图片自动上传到微信素材库并替换 URL
- 第一张图作为封面（thumb_media_id）
- `.wechat-sync.json` 记录内容 hash，防止重复同步
- access_token 的 IP 白名单错误（40164）有中文提示

### 技术栈
- Node 22 `--env-file=.env` 原生加载环境变量（无需 dotenv）
- `marked` v18（Markdown→HTML）、`gray-matter` v4（front matter 解析）
- 纯 Node 内置 `https` 模块调微信 API，无额外 HTTP 库依赖
